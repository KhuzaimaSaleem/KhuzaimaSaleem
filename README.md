## 🚀 Featured Project

### 🖼️ [Image Captioning with PyTorch](https://github.com/KhuzaimaSaleem/image-captioning-pytorch)
An end-to-end deep learning project that generates natural language descriptions for images.

- **Encoder:** pretrained ResNet50 extracts image features
- **Decoder:** Transformer with attention generates captions word by word
- **Data:** Flickr8k dataset (about 40,000 image-caption pairs)
- **Demo:** Gradio web app, upload any image and get a caption
- **Training:** loss dropped from 4.32 to 2.88 over 10 epochs

`PyTorch` `Torchvision` `Transformers` `Gradio` `Google Colab`
